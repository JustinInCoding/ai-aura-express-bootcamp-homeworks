# 美团首页有哪些 nlp 任务

> 参考图片：图1 = 美团首页（搜索框 + 分类金刚位 + 商家信息流），图2 = 小团 AI 助手页面

## 一、首页搜索部分（图1 顶部搜索框）

### 1. 文本匹配任务（1.6）
- 用户输入"麦当劳(周浦康路店)"，系统要计算 Query 和海量商户/商品名称、品类的**语义相似度**，按相关性排序返回结果。
- 核心难点正是文档里说的：不能只看字面重叠。搜"早餐"要能召回"包子铺""豆浆油条店"这些名字里没有"早餐"二字的店，靠语义匹配而不是关键词比对。
- 搜索 sug 联想（输入"麦当"补全出"麦当劳(周浦康路店)"）也依赖 Query 与历史查询/商户名的匹配。

### 2. 序列标注 / NER（1.2）
- 要理解"麦当劳(周浦康路店)"这句 Query，需要先"抠"出关键实体：
  - 品牌名：麦当劳
  - 地址/分店：周浦康路店
- 抠出结构化实体后才能精确路由到具体门店，这就是文档里"智能音箱先 NER 再执行业务"的同款流程。

### 3. 信息抽取（1.5）
- Query 理解本质就是信息抽取：把一句自由文本变成（品牌, 品类, 位置）这样的结构化"表格"，供检索系统使用。

## 二、分类金刚位（图1 中部：外卖、团购、酒店/旅行、闪购、看病买药、美食、休闲娱乐、拼好饭、电影演出……）

### 4. 文本分类——主题分类（1.1）
- 每个商户/商品都要被自动归入提前定好的**有限类别集合**（外卖 / 美食 / 酒店旅行 / 休闲娱乐……），类别是人提前规定好的，模型只做选择——正是文本分类的定义。
- 很多商户跨品类（一家店既是"美食"又属于"休闲娱乐"），属于文档提到的**多标签分类**的扩展形式。

## 三、首页信息流（图1 下部：肯德基星球欢乐套餐、老娘舅梅干菜烧肉、古法现熬粥、四季淮南牛肉汤……）

### 5. 文本匹配（1.6）——推荐系统
- 文档 1.6 明确列了"推荐系统：判断用户兴趣和候选内容是否匹配"这个应用。首页 feed 流给不同用户展示不同商家，背后要把**用户画像/兴趣文本**与**商品标题、卖点和文案**做语义相似度计算再排序。

### 6. 信息抽取 / NER（1.5、1.2）
- 商家卡片上的文案需要预先抽取出结构化字段才能展示和检索：
  - "四季-淮南牛肉汤(周浦店)" → 品牌：四季，品类：淮南牛肉汤，位置：周浦店
  - "浦东区牛肉汤店热度榜第1名" → 抽出（商户, 位于, 浦东区）、榜单关系，类似关系抽取的三元组
  - "4.6分""已售4万+" → 从文本中抽取数值型属性做槽位填充

### 7. 文本分类——情感分析（1.1）
- 卡片上"4.6 分""已售 4 万+"这类口碑数据，来自对海量用户评论的**情感分析**（好评/差评自动打标后统计聚合），文档里"电商领域统计好评度 90%"就是同一个场景。
- 评论还会同时做**主题分析**（归到"味道/配送/包装/价格"等标签），一条评论同时打情感 + 主题两类标签，即文档说的"同一条评论完全可以同时做这两种分类"。

## 四、小团 AI 助手（图2）

### 8. 文本理解 + 文本生成（1.4、1.3）——LLM 对话
- "今日嗨吃嗨玩，有什么计划？"以及对话式回答，本质是大语言模型：文本进、文本出，"根据上文预测下一段文字"（1.3），同时需要"读懂"用户意图（1.4）。

### 9. 序列标注 / 槽位填充（1.2）——意图理解
- 小团的四个入口"外卖下单 / 餐厅预订 / 发现附近 / 玩乐预订"，用户说"帮我订周末两人位的餐厅"时，要先做意图识别 + 槽位填充：
  - 意图：餐厅预订
  - 时间：周末；人数：2 人
- 这就是文档"快递地址自动填充表单"的同款 NER/槽位填充流程。

### 10. 文本匹配（1.6）——FAQ/服务路由
- "一键领券"下的"奶茶券 / 咖啡券 / 甜品券"快捷标签，以及用户口语化提问路由到对应服务，都要把用户的话**语义匹配**到预定义的标准意图/券类目上——换种问法也能匹配上。

### 11. 多模态任务（1.7）
- 小团卡片"文字 + 图片"混排，用户拍照问"这是什么菜/这家店怎么样"属于**视觉问答（VQA）**；
- 首页图片素材要可被搜索，需要先**图像描述生成（看图说话）**把图转成文字建索引；
- 语音输入"按住 说话"涉及语音 → 文本（ASR），是语音模态与文本模态的打通，广义上也属于多模态范畴。

## 总结表

| 页面位置 | 功能 | NLP 任务类别 | 参考文档章节 |
| --- | --- | --- | --- |
| 搜索框 | 搜索排序 / sug 联想 | 文本匹配 | 1.6 |
| 搜索框 | Query 理解（品牌+门店） | 序列标注 NER / 信息抽取 | 1.2 / 1.5 |
| 金刚位 | 商户归入外卖/美食/酒店等类目 | 文本分类（主题分类，多标签） | 1.1 |
| 信息流 | 个性化推荐排序 | 文本匹配 | 1.6 |
| 信息流 | 商家卡片结构化字段（品牌/榜单/销量/评分） | 信息抽取 / 槽位填充 | 1.5 / 1.2 |
| 信息流 | "4.6 分、已售 4 万+"口碑统计 | 文本分类（情感分析 + 主题分析） | 1.1 |
| 小团 | 对话问答 | 文本理解 + 文本生成（LLM） | 1.4 / 1.3 |
| 小团 | 意图识别 + 参数抽取（时间/人数/地点） | 序列标注 / 槽位填充 | 1.2 |
| 小团 | 快捷标签路由（奶茶券/咖啡券/甜品券） | 文本匹配（FAQ 式） | 1.6 |
| 小团/图片 | 看图问答、图片可搜索、语音输入 | 多模态 | 1.7 |
