# 评论打分模型方案设计（只做方案，不落地）

> 任务定义：给定一条豆瓣电影评论文本，预测用户给出的星级评分（1~5）。
> 即：**文本 → 星级的有序多分类 / 回归问题**。目标变量来自 `comments.csv` 的 RATING 字段，输入特征以 CONTENT 为主，辅以少量结构化特征。

## 1. 问题建模方式的选择

| 方案 | 形式 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| A. 多分类（5 类 softmax） | 分类 | 指标直观 | 忽略星级有序性，2/3 星混淆不受惩罚 | 备选 |
| B. **有序回归 / 相邻类别**（ordinal） | 序数 | 尊重星级有序性，更贴合任务本质 | 实现稍复杂（可用 CORAL / 阈值法） | **推荐** |
| C. 回归（1~5 连续值 + 取整） | 回归 | 直接输出均值型分数 | 对极端分预测收缩，取整边界抖动 | 作为评估视角保留 |

**最终建议**：以有序分类（B）为主模型，同时报告"预测值取整"口径的回归指标（C），兼顾两种理解方式。

## 2. 数据准备

### 2.1 数据集构建

1. 使用 EDA 产出的清洗数据：剔除 RATING 缺失/越界、CONTENT 为空、与 movies.csv 无法关联的记录；
2. 去重：同一 `(CREATOR, MOVIEID)` 保留一条（按 EDA 结论决定保留最新或最短）；
3. 可选过滤：长度 < 5 字的评论单独统计，训练时可降权或剔除（用消融实验验证影响）。

### 2.2 数据切分（关键设计，防泄漏）

- **主切分**：按电影（MOVIEID）分组切分 train/val/test = 8/1/1，保证同一部电影的评论不跨集。
  - 理由：同一电影内评论高度相关（同题材、同口碑氛围、文本互相模仿），随机切分会因"记得这部电影大概几分"而虚高指标；
  - 分组切分用 `GroupShuffleSplit` / `GroupKFold`，并按 RATING 分层（电影太多无法严格分层时，改为检查各集星级分布一致即可）。
- **辅助切分**：按 TIME 切分（训练集=早于某日期，测试集=晚于），检验模型对未来评论的泛化，对齐 EDA 发现的时间漂移。
- 两套切分指标都报告，若差距大则说明模型部分依赖电影级先验而非文本本身。

### 2.3 类别不平衡处理

按 EDA 的 RATING 分布结论（预期 J 型分布）选择：

- 类别权重（weighted cross-entropy / class weight）为默认做法；
- 或对多数类欠采样、少数类过采样（优先权重法，避免丢失数据）；
- 评估以宏平均（macro-F1 / macro-MAE）为主指标，避免被多数类掩盖。

## 3. 特征工程

### 3.1 文本特征

| 层级 | 方案 | 说明 |
|---|---|---|
| 基础清洗 | 去除 URL、HTML 转义、多余空白、表情符号规范化 | 依据 EDA 文本质量结论 |
| 分词 | jieba（中文）；保留 bigram | EDA 已确认否定结构（"不好看"）存在，必须保留 bigram |
| 词袋/TF-IDF | unigram + bigram，max_features 5~10 万，min_df≥3 | baseline 与轻量方案的核心特征 |
| 嵌入 | 预训练中文词向量（fastText / Tencent embeddings）均值池化 | 中间层方案 |
| 预训练模型 | 中文 RoBERTa-wwm / MacBERT 微调，直接以原文输入 | 端到端方案，无需手工分词 |

### 3.2 辅助结构化特征（可选，用于消融验证）

- 评论长度（字符数、词数）——EDA 若发现长度与星级相关则纳入；
- 评论发布时间距数据采集的时间差；
- 用户历史评分均值（仅当该用户还有其他评论在训练集内时可用，注意泄漏防护：只用训练集统计）；
- 电影 ID/名称**不直接作为特征**（避免模型退化为"查表预测电影分"），只用于分组切分。

## 4. 模型方案（由浅入深，逐级对比）

### 阶段 1：Baseline（必须先做，建立下界）

- **TF-IDF + LogisticRegression / LinearSVC**（有序任务可用回归型 Ridge 代替）；
- 目的：验证文本信号强度，得到可解释的权重词表（对照 EDA 的星级区分词），一切后续模型必须显著优于它。

### 阶段 2：轻量进阶

- **fastText 监督分类**（bigram 嵌入平均，训练极快，适合大 corpus 调参迭代）；
- **TF-IDF + LightGBM**（可融合结构化特征）。

### 阶段 3：预训练语言模型微调（预期主力）

- **chinese-roberta-wwm-ext（base）微调**，输出层按第 1 节选定的有序结构（CORAL 头或普通 5 类头）；
- 超参：lr 2e-5、batch 32、max_len 128（EDA 长度 P99 决定，多数短评 64 足够，训练快一倍）、早停按 val macro-MAE；
- 数据量约 40 万条，如资源受限可先抽样 10 万条完成流程，再决定是否全量。

### 阶段 4（可选）：大模型路线

- 用 LLM API 对小样本（如 1000 条）做 zero/few-shot 打分，作为对照组，衡量"专门训练的小模型 vs 通用大模型"的成本收益差——对作业场景有很好的讨论价值。

## 5. 评估方案

### 5.1 指标

| 指标 | 用途 |
|---|---|
| **macro-MAE（星级平均绝对误差）** | 主指标，对各类一视同仁 |
| Exact Accuracy（命中率） | 直观可解释 |
| **±1 星准确率** | 有序任务的关键业务指标（差一星可接受） |
| QWK（Quadratic Weighted Kappa） | 序数一致性，与"人评人"口径可比 |
| macro-F1 / 分星级混淆矩阵 | 定位具体错在哪两档之间 |

### 5.2 分析项

- **混淆矩阵热力图**：预期主要错误集中在相邻档（2↔3、3↔4），若出现 1↔5 跨档错误则模型有严重问题；
- **分长度段误差**：短评（<10 字）误差 vs 长评误差，验证 EDA 的长度结论；
- **分电影聚合评估**：把测试集预测按电影取平均，与电影真实平均分比较（RMSE），回答"从评论预测一部电影的口碑"这一衍生问题；
- **Baseline vs 主模型差距** + 消融（去 bigram、去结构化特征、去类别权重）。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| J 型分布导致中间星训练样本少 | 类别权重 + macro 指标；必要时对中间档过采样 |
| 短文本信息量不足 | 最小长度过滤消融；RoBERTa 对短文本天然友好 |
| 讽刺/网络用语误判 | 接受为误差来源并写入分析；bigram 与预训练模型部分缓解 |
| 电影级泄漏虚高指标 | 分组切分 + 时间切分双口径报告 |
| 评分标准因人而异（同样文本不同人给不同分） | 报告人类一致性上界估计（同电影内评分离散度），说明任务天花板 |
| 编码与清洗引入脏数据 | 复用 EDA 清洗管道；movies.csv GBK 读取仅在 join 时需要，建模主流程只依赖 comments.csv |

## 7. 里程碑（建议顺序）

1. EDA 完成并产出清洗数据（对接 `01-eda-plan.md` 第 9 节的 5 个结论）；
2. 数据管道 + 双切分实现；
3. 阶段 1 baseline 出指标；
4. 阶段 3 RoBERTa 微调出指标；
5. 评估分析（混淆矩阵、分长度、分电影）+ 消融；
6. 报告：结论、误差分析、局限与改进方向。
