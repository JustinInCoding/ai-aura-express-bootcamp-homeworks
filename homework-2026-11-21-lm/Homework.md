基于文本表示方法（**n-grams**），通过**统计学**实现一个语言模型（自己试着做一个，参数中 n 指 n_grams，拉普拉斯平滑 k 可以取 1）。需要关注的三个要素：

- **样本**：语料里有哪些句子
- **词汇表大小**：v
- **拉普拉斯平滑**：k（防止没见过的搭配概率直接为 0）

### 语言模型小案例步骤参考

老师讲解了一个小案例，实现步骤如下（具体资料没有给到，可参考以下流程）：

1. **切词**：把句子切成词（用 jieba 分词）
2. **加标记**：标出开头 `<s>` 和结尾 `</s>`（让模型知道句子从哪开始、到哪结束）
3. **数次数**：把三句话放一起统计 n-gram 出现次数（这就是"训练过程"，本质是数数！）
4. **算概率**：把次数转换成条件概率：

   ```
   p(爱 | 我) = (ngram 次数 + k) / (前词出现总次数 + k × v)    # v = 词表大小
   ```

5. **查候选**：前一个词定了，下一个词有哪些选择？各自概率多少？
6. **生成句子**：**贪心生成** —— 每次挑概率最大的词接上去。注意需要 `max_length` 兜底防止无限生成，遇到 `</s>` 则正常停止
7. **评估**，两种方式：
   1. **困惑度 PPL**：`ppl = 2^(−(log2 p1 + log2 p2 + ... + log2 pn) / n)`，n 指句子里有 n 个词
   2. **整句概率**：把每一对接法的概率**相乘**，看整句话像不像人话（是否连贯）
