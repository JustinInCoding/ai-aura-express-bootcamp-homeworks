## 二、电商场景数据集详细介绍

### A1. Online Retail 在线零售交易数据（推荐首选）

- **平台**：Kaggle / UCI Machine Learning Repository（英国在线零售商 2010-12-01 至 2011-12-09 全部交易）
- **下载链接**：
  - Kaggle 页面：https://www.kaggle.com/datasets/vijayuv/onlineretail
  - Kaggle API：`kaggle datasets download -d vijayuv/onlineretail`
  - UCI 原始来源：https://archive.ics.uci.edu/ml/datasets/Online+Retail
  - Kaggle 备选镜像：https://www.kaggle.com/datasets/ulrikthygepedersen/online-retail-dataset
- **数据规模**：541,909 行 × 8 列（约 22 MB），远超信用卡数据集（8,950×18），数据量充足
- **特征字段**：

| 字段 | 类型 | 含义 |
|------|------|------|
| InvoiceNo | 类别 | 发票编号（6 位数字，B/C 开头为退货/取消单） |
| StockCode | 类别 | 商品库存代码 |
| Description | 文本 | 商品描述 |
| Quantity | 数值 | 商品数量（负数表示退货） |
| InvoiceDate | 时间 | 发票日期（日期时间类型） |
| UnitPrice | 数值 | 单价 |
| CustomerID | 数值 | 客户 ID（**缺失约 24.9%**，约 135,080 行） |
| Country | 类别 | 客户所在国家（38 个国家） |

- **是否有标签**：无（原始交易流水，属于无监督场景；可自行构建 RFM 特征）
- **适合本项目的原因**：
  - **真正的电商场景**：英国在线零售商的真实交易流水；
  - **数据规模大**：54 万行交易，聚合后可得数千个客户样本，达到甚至超过信用卡数据集规模；
  - **特征工程空间大**：可构建经典 **RFM 模型**（Recency 最近购买时间 / Frequency 购买频率 / Monetary 消费金额），这是电商客户分群最经典的方案；
  - **缺失值 + 脏数据处理丰富**：CustomerID 缺失 24.9%、Description 缺失、Quantity 负数（退货）、B/C 开头退货单，训练数据处理能力；
  - **时间序列维度**：可按月/季分析客户行为演变。
- **注意点**：
  - 需将交易流水按 CustomerID 聚合为「客户 × RFM 特征」的矩阵（聚合后约 4,300+ 客户）；
  - 剔除 CustomerID 缺失的订单、Quantity/UnitPrice 为负或零的异常记录；
  - RFM 特征需标准化/对数变换（Monetary 右偏严重）后再聚类。

### A2. Online Shoppers Purchasing Intention 在线购物者购买意图

- **平台**：UCI Machine Learning Repository / Kaggle
- **下载链接**：
  - Kaggle 页面：https://www.kaggle.com/datasets/imakash3011/online-shoppers-purchasing-intention-dataset
  - Kaggle API：`kaggle datasets download -d imakash3011/online-shoppers-purchasing-intention-dataset`
  - Kaggle 备选：https://www.kaggle.com/datasets/henrysue/online-shoppers-intention
  - UCI 原始来源：https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset
- **数据规模**：12,330 行（会话）× 18 列，约 1.5 MB（规模超过信用卡数据集 8,950×18）
- **特征字段**（18 个）：
  - 页面访问类：`Administrative`、`Administrative_Duration`、`Informational`、`Informational_Duration`、`ProductRelated`、`ProductRelated_Duration`
  - 转化率类：`BounceRates`（跳出率）、`ExitRates`（退出率）、`PageValues`（页面价值）
  - 时间/环境类：`SpecialDay`（临近特殊节日程度）、`Month`（月份）、`OperatingSystems`、`Browser`、`Region`、`TrafficType`、`VisitorType`（访客类型）、`Weekend`（是否周末）
  - **标签**：`Revenue`（该会话是否产生购买，布尔）
- **是否有标签**：**有**（Revenue 二分类：约 84.5% 未购买 / 15.5% 购买）
- **适合本项目的原因**：
  - **电商场景明确**：来自真实购物网站的访问会话数据（论文来源：Sakar et al., Neural Computing and Applications, 2019）；
  - **自带标签可量化评估**：训练时隐藏 Revenue 标签做无监督聚类，聚类后用 ARI/NMI/纯度等指标**客观对比 K-means 与 DBSCAN 的聚类质量**；
  - 规模与特征维度（12,330×18）与信用卡数据集（8,950×18）相当，符合你的规模要求；
  - 特征全部数值化，预处理简单，可快速跑通。
- **注意点**：`Revenue` 标签仅用于评估阶段，训练聚类时隐藏；类别不平衡（84.5% vs 15.5%）本身也是分析素材；`Month`、`VisitorType` 等类别字段需编码。

### A3. 淘宝用户购物行为数据集（UserBehavior，阿里天池）

- **平台**：阿里云天池
- **下载链接**：
  - 页面一：https://tianchi.aliyun.com/dataset/649
  - 页面二：https://tianchi.aliyun.com/dataset/224006（"可做用户聚类分析"标注版）
  - 需登录天池账号，完成学生认证可免审批下载
- **数据规模**：约 1 亿条用户行为记录（约 98 万用户 × 416 万商品 × 9,439 个类目），时间跨度 2017-11-25 至 2017-12-03
- **特征字段**：

| 字段 | 类型 | 含义 |
|------|------|------|
| user_id | 数值 | 用户 ID |
| item_id | 数值 | 商品 ID |
| category_id | 数值 | 商品类目 ID |
| behavior_type | 类别 | 行为类型：pv 浏览 / cart 加购 / fav 收藏 / buy 购买 |
| timestamp | 数值 | 行为发生时间（Unix 时间戳） |

- **是否有标签**：无（行为日志，可自行聚合特征；behavior_type 可作弱标签）
- **适合本项目的原因**：
  - **最真实的国内电商场景**：阿里淘宝真实脱敏行为日志，报告最有说服力；
  - **规模巨大**：1 亿条行为，远超要求；
  - **可做用户画像聚类**：将行为日志聚合为「用户 × 行为特征」矩阵（如各行为次数、购买转化率、活跃天数等），再做用户分群。
- **注意点**：
  - 1 亿行文件较大（约 1 GB+），**建议抽样**（如取 10 万用户）或使用天池实验室在线环境处理；
  - 需自行设计特征聚合逻辑（用户级特征工程）；
  - 本地电脑配置不足时优先选择 A1 或 A2。

## 四、推荐建议（电商场景）

| 场景 | 推荐 |
|------|------|
| 电商场景 + 规模充足 + 教程生态完善 | **A1 Online Retail**（首选） |
| 电商场景 + 规模适中 + 想量化对比聚类质量（有标签） | **A2 在线购物者购买意图** |
| 电商场景 + 追求最真实大规模国内数据（可接受抽样/聚合） | **A3 淘宝 UserBehavior** |

> 综合推荐：**A1 Online Retail 在线零售交易数据**。
> 理由：
> 1. 真实电商交易场景，541,909 行，规模远超要求；
> 2. 可完整演示「数据清洗 → RFM 特征工程 → 标准化 → K-means/DBSCAN 聚类 → 客户价值分层」全流程，项目内容最充实；
> 3. 无标签的纯无监督场景，最贴合 K-means 与 DBSCAN 聚类的项目目标；
> 4. Kaggle + UCI 双平台可下载，资料丰富。

## 附录：原推荐数据集详细介绍

（原 1-5 数据集的详细字段、链接、注意点等信息，见较早版本推荐，核心内容概述如下：）

### 1. 商场客户细分数据（Mall Customer Segmentation Data）
- 链接：https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python
- API：`kaggle datasets download -d vjchoudhary7/customer-segmentation-tutorial-in-python`
- 规模：200×5；字段：CustomerID、Gender、Age、Annual Income、Spending Score；无标签
- 看点：肘部法则/轮廓系数选 K 的教学标准案例；注意 Gender 需编码、特征需标准化

### 2. 信用卡客户聚类数据（CC GENERAL）
- 链接：https://www.kaggle.com/datasets/arjunbhasin2013/ccdata
- API：`kaggle datasets download -d arjunbhasin2013/ccdata`
- 规模：8,950×18；17 个行为特征（余额/消费/预借现金/频率/额度等）+ CUST_ID；无标签
- 看点：缺失值处理（MINIMUM_PAYMENTS、CREDIT_LIMIT）+ 标准化 + PCA 降维；注意删 CUST_ID

### 3. 批发客户数据（Wholesale Customers Dataset）
- 链接：https://www.kaggle.com/datasets/binovi/wholesale-customers-data-set（UCI 原版：https://archive.ics.uci.edu/dataset/292/wholesale+customers）
- 规模：440×8；字段：Channel、Region（伪标签）+ Fresh/Milk/Grocery/Frozen/Detergents_Paper/Delicatessen 六类商品年度支出
- 看点：离群点多，展示 DBSCAN 噪声处理优势；Channel 可作伪标签做 ARI/NMI 外部评估

### 4. 电商用户行为分析数据集（阿里天池）
- 链接：https://tianchi.aliyun.com/dataset/216886
- 规模：1,000 条交易（模拟中文电商）；字段：用户 ID、姓名、性别、年龄、城市、购买行为；无标签
- 看点：中文业务场景 + RFM 特征工程；注意规模偏小

### 5. 鸢尾花数据集（Iris，OpenDataLab）
- 链接：https://opendatalab.com/OpenDataLab/iris；CLI：`openxlab dataset download --dataset-repo "OpenDataLab/iris"`
- 规模：150×5；4 个花部测量特征 + species（3 类）；有标签
- 看点：自带真实标签，ARI/NMI/纯度量化对比两种聚类算法；注意训练时隐藏标签
