# 数据字典（Online Retail）

> 数据来源：UCI Machine Learning Repository — Online Retail Dataset（UK-based 跨国在线零售，2010-12-01 ~ 2011-12-09，共 373 天）。
> 本字典覆盖：原始字段 → 清洗规则 → 工程字段 → 最终建模数据集口径。所有数值均为本项目实测。

## 1. 原始字段（8 列）

| 字段 | 类型 | 含义 | 实测范围 / 示例 |
|------|------|------|----------------|
| `InvoiceNo` | 字符串 | 订单号（每笔交易唯一；以 **C 开头 = 取消单**） | 如 `536365`、`C536379` |
| `StockCode` | 字符串 | 商品代码（SKU） | 如 `85123A`、`22197` |
| `Description` | 字符串 | 商品描述 | 如 `WHITE HANGING HEART T-LIGHT HOLDER`；**1,454 行缺失** |
| `Quantity` | 整数 | 每行购买数量（**负数 = 退货**） | 均值 10.66 / 中位 3 / 最大 80,995 |
| `InvoiceDate` | datetime | 交易时间 | `2010-12-01 08:26` ~ `2011-12-09 12:50` |
| `UnitPrice` | 浮点 | 单价（英镑 £；**0 = 异常**） | 均值 4.67 / 中位 2.08 / 最大 38,970 |
| `CustomerID` | 浮点→整数 | 客户 ID（**24.9% 缺失**） | 覆盖 4,338 个客户 |
| `Country` | 字符串 | 客户所在国家 | 英国占 91.4%（行口径）/ 90.4%（客户口径），共 38 个国家 |

## 2. 清洗规则（与 `src/data_preprocessing.py` 一致）

按顺序执行 4 类剔除 + 去重：

| 步骤 | 规则 | 剔除行数 | 说明 |
|------|------|---------|------|
| ① | `CustomerID` 缺失 | 135,080 | 无法关联客户 |
| ② | `Quantity <= 0` | 10,624 | 含负数（退货）与 0 |
| ③ | `UnitPrice <= 0` | 2,517 | 含 0 元（2,515）与负价（2） |
| ④ | `InvoiceNo` 以 `C` 开头 | 9,288 | 取消单 |
| ⑤ | 完全重复行 | 5,192 | 去重 |

**结果**：541,909 行 → 397,884 行（剔脏数据）→ **392,692 行（去重后）**；覆盖 **18,532 个有效订单 / 4,338 个客户**。

## 3. 工程字段（特征工程产物）

| 字段 | 计算方式 | 说明 |
|------|---------|------|
| `Amount` | `Quantity × UnitPrice` | 每行交易金额（英镑），仅用于聚合 |
| `Recency` | `基准日(2011-12-09) − 最近一次购买日期`（天数） | 越小越活跃；计算前需 `normalize()` 归零，否则当天购买会出现 -1 |
| `Frequency` | `InvoiceNo` 去重计数 | 客户购买过的不同订单数 |
| `Monetary` | `Amount` 求和 | 客户累计消费金额 |
| `log1p(R/F/M)` | `np.log1p(x)` | 压缩右偏长尾（偏度 460→1.03），聚类用 |
| `X_scaled` | StandardScaler(log1p(R/F/M)) | 标准化后特征矩阵（均值 0 / 方差 1），shape `(4338, 3)` |
| `Cluster_KM` | K-means(K=4) 标签 | 0~3，最终采用的分群 |
| `Cluster_DB` | DBSCAN(eps=0.6, min_samples=5) 标签 | 0~1 及 -1（噪声 43 个） |

## 4. 最终建模数据集

| 口径 | 值 |
|------|-----|
| 客户数（样本量） | 4,338 |
| 特征数 | 3（Recency / Frequency / Monetary，log1p + 标准化） |
| 特征矩阵 | `(4338, 3)`，连续值，可直接用于距离类聚类算法 |
| 标签 | `Cluster_KM`（4 簇，业务标签：活跃高价值 / 沉睡低价值 / 近期低频·新客 / 中等价值） |
