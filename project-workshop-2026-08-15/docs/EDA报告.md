> 对应 `notebooks/analysis.ipynb` 第 1~6 节。所有数字为本项目实测（Python 3 + pandas + matplotlib/seaborn）。

## 1. 数据概况

| 指标 | 值 |
|------|-----|
| 原始规模 | 541,909 行 × 8 列 |
| 时间跨度 | 373 天（2010-12-01 ~ 2011-12-09） |
| 覆盖国家 | 38 个 |
| 原始客户数 | 4,372（含脏数据客户，清洗后 4,338） |

## 2. 数据质量

### 2.1 缺失值
- **CustomerID 缺失 135,080 行（24.9%）**：这些是游客订单，无法进行客户级分析，清洗时剔除。
- Description 缺失 1,454 行（0.3%）：不影响本项目的客户级分析。

![缺失值热力图（黄=缺失，紫=有值）](../results/figures/eda_01_缺失值热力图.png)

### 2.2 异常值
| 类型 | 行数 | 处理 |
|------|------|------|
| `Quantity < 0`（退货） | 10,624 | 剔除 |
| `UnitPrice = 0`（0 元/赠品） | 2,515 | 剔除 |
| `UnitPrice < 0` | 2 | 剔除 |
| `C` 开头取消单 | 9,288 | 剔除 |
| 完全重复行 | 5,192 | 去重 |

**清洗后**：392,692 行 / 18,532 订单 / 4,338 客户，数据干净且客户可关联。

## 3. 数值分布与对数变换

两个核心数值字段都呈**严重右偏长尾**（少量极端客户拉高均值）：

| 指标 | Quantity | UnitPrice |
|------|----------|-----------|
| 均值 | 10.66 | 4.67 |
| 中位数 | 3.00 | 2.08 |
| 最大值 | 80,995 | 38,970 |
| 99 分位 | 100 | 18 |

### log1p 变换效果（关键发现）
| 指标 | Quantity | UnitPrice |
|------|----------|-----------|
| 偏度 | 460.1 → **1.03** | 206.3 → **1.30** |
| 最大/中位数 | 26,998 倍 → **8.2 倍** | 18,736 倍 → **9.4 倍** |
| 99 分位占最大比例 | 0.1% → **40.8%** | 0.0% → **27.9%** |

**结论**：变换前极值几乎吞掉整个分布（99 分位仅占最大值的 0.1%），变换后长尾被有效压缩、分布形态正常，适合后续基于距离的聚类。这也是为什么最终特征工程采用 log1p（而非幂变换/分箱）。

## 4. 维度分析

### 4.1 时间
- 月度交易量整体上升，11-12 月（购物季）明显冲高。
- 数据末日在 2011-12-09，作为 RFM 的 Recency 基准日。

![月度交易行数走势](../results/figures/eda_02_月度交易走势.png)

### 4.2 国家
- **英国一家独大**：行口径占 91.4%，客户口径占 90.4%。
- 其余 37 个国家合计不足 10%，样本稀疏，客户级聚类不按国家细分。

![交易行数 Top15 国家](../results/figures/eda_06_国家分布Top15.png)

### 4.3 客户与订单
| 指标 | 值 |
|------|-----|
| 有效订单数 | 18,532 |
| 客户数 | 4,338 |
| 客户平均订单数 | 4.27 |
| 客户订单数中位数 | 2 |
| 下单最多客户 | 209 单 |

- 客户订单数同样右偏：**一半客户只下过 ≤2 单**，少数大客户贡献大量订单——典型的「二八」结构，与后面聚类出的「沉睡低价值」大簇（37.7%）相互印证。

![客户订单数分布（截断 50）](../results/figures/eda_07_客户订单数分布.png)

## 5. RFM 特征分布（客户级，4,338 客户）

- **Recency**：大量客户长期未回购（右偏），中位数约 50 天，尾部超过 300 天。
- **Frequency**：高度右偏，多数客户仅 1~2 单，头部客户几十单。
- **Monetary**：极右偏，中位数约 673 英镑，头部客户超十万英镑。

三者经 log1p + 标准化后用于聚类。

![RFM 原始分布（严重右偏）](../results/figures/fe_01_RFM原始分布.png)

![log1p 变换后的 RFM 分布（形态接近正态）](../results/figures/fe_02_RFM_log1p分布.png)

## 6. EDA 小结（对建模的启示）

1. **必须清洗**：24.9% 无客户 ID + 异常数量/单价 + 取消单，占原始 27.5%。
2. **必须对数变换**：三个核心特征严重右偏，不做变换则极端客户会主导聚类距离。
3. **客户结构右偏**：少数活跃高价值客户 vs 大量沉睡客户，聚类应能刻画这种分层。
4. **英国主导**：结论主要适用于英国市场，其余国家样本不足不单独建模。
