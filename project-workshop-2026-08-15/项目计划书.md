## 一、项目背景

### 1.1 行业背景

随着电子商务的迅猛发展，线上零售市场竞争日趋激烈。企业积累了海量的用户交易数据，但"如何从数据中挖掘客户价值、实现精细化运营"成为普遍痛点。传统"一刀切"的营销方式效率低下，而**客户分群（Customer Segmentation）**将客户划分为具有相似消费特征与价值的群体，从而支撑差异化营销、库存优化与个性化推荐，已成为电商精细化运营的基石。

### 1.2 技术背景

**聚类（Clustering）**是机器学习中最重要的无监督学习方法之一，能够在没有标注标签的情况下，依据样本间的相似性自动将数据划分为若干簇。在客户分群场景中：

- **K-means**：基于划分的经典算法，原理简单、计算高效、易于解释，是客户分群应用最广泛的算法之一；
- **DBSCAN**：基于密度的算法，能够发现任意形状的簇并自动识别噪声点（离群客户），对参数设置敏感但对离群值鲁棒。

两种算法原理不同、适用场景各异，**在同一数据集上系统对比两者表现**，既能深入理解算法特性，也具有真实的业务参考价值（如识别高价值客户与异常客户）。

### 1.3 数据背景

本项目采用 UCI 机器学习库公开的 **Online Retail** 数据集（Kaggle 亦提供镜像），收录了英国某在线零售商 **2010-12-01 至 2011-12-09** 期间的全部交易记录，共 **541,909 行、8 列**，数据规模超过信用卡客户聚类数据集（8,950 × 18），数据量充足且场景真实。

## 二、项目目标

### 2.1 总体目标

基于 Online Retail 交易数据构建客户级 RFM 特征，分别使用 **K-means** 与 **DBSCAN** 两种聚类算法对客户进行分群，系统对比两种算法的聚类效果与业务解释性，最终输出可落地的客户价值分层方案与差异化营销策略建议。

### 2.2 具体目标

1. **数据工程目标**：完成交易数据的清洗（缺失值、异常值、退货单处理），构建客户级 RFM 特征矩阵；
2. **算法实现目标**：使用 scikit-learn 实现 K-means 与 DBSCAN 聚类，掌握两种算法的原理与调参方法（K 值选取、eps/min_samples 确定）；
3. **对比评估目标**：从内部指标（轮廓系数、DBI、CH 指数）、外部参照（聚类簇特征画像）与业务可解释性三个维度，系统对比 K-means 与 DBSCAN；
4. **业务应用目标**：基于聚类结果划分客户价值层级（高价值/普通价值/低价值/流失风险/异常客户），提出差异化营销建议。

## 三、项目方案

### 3.1 技术路线总览

```
数据获取 → 数据探索(EDA) → 数据清洗 → RFM特征工程 → 特征标准化
        → K-means聚类 ─┐
        → DBSCAN聚类 ──┼→ 对比评估（内部指标+簇画像） → 客户价值分层
        → 可视化(散点/PCA/t-SNE/箱线图) ─┘        → 营销策略建议 → 结论
```

### 3.2 数据预处理

| 步骤 | 处理内容 | 具体方法 | 说明 |
|------|----------|----------|------|
| 1. 缺失值处理 | `CustomerID` 缺失约 24.9%（约 135,080 行）；`Description` 缺失约 0.27% | 缺失 CustomerID 的订单无法关联客户，**直接剔除**；Description 缺失不影响 RFM 构建，可保留 | 剔除后约 406,829 条有效交易 |
| 2. 异常值处理 | `Quantity` 为负（退货）；`UnitPrice` 为负或为 0（错误/赠品） | 剔除 Quantity ≤ 0 与 UnitPrice ≤ 0 的记录 | 保证金额计算正确性 |
| 3. 退货单处理 | 发票号以 C 开头（取消订单） | 剔除 InvoiceNo 以 "C" 开头的记录 | 避免虚增消费金额 |
| 4. 金额计算 | 单笔交易金额 | `Amount = Quantity × UnitPrice` | 新增字段 |
| 5. 日期解析 | `InvoiceDate` 为字符串 | 转换为 datetime 类型，提取年月日 | 用于计算 Recency |

### 3.3 特征工程（RFM 模型）

将交易流水按 `CustomerID` 聚合为 **客户 × RFM 特征** 矩阵（聚合后约 4,300+ 客户）：

| 特征 | 全称 | 计算方式 | 业务含义 |
|------|------|----------|----------|
| R（Recency） | 最近购买时间 | 分析基准日（2011-12-09 数据末日）距该客户最后一次购买的天数 | 越小表示越活跃 |
| F（Frequency） | 购买频率 | 该客户去重后的发票数（InvoiceNo 唯一值计数） | 越大表示购买越频繁 |
| M（Monetary） | 消费金额 | 该客户所有有效交易 `Quantity × UnitPrice` 之和 | 越大表示贡献越高 |

**特征优化处理：**
- **分布校正**：R、F、M 均呈右偏分布，对 F、M 做对数变换 `log1p` 缓解偏态；R 较小值聚集，可视情况做倒数或标准化；
- **标准化**：对最终特征矩阵使用 `StandardScaler`（或 MinMaxScaler）统一量纲——K-means 基于欧氏距离、DBSCAN 基于密度，量纲差异会严重扭曲结果，标准化是必要的；
- **可选降维**：若需二维可视化，可使用 PCA 降至 2-3 维（保留 85%+ 方差），t-SNE 用于结果展示。

### 3.4 K-means 与 DBSCAN 对比设计

#### 3.4.1 K-means 方案

- **原理**：将样本划分为 K 个簇，迭代最小化簇内平方和（SSE/惯性）：
  \[
  SSE = \sum_{i=1}^{K}\sum_{x \in C_i} \|x - \mu_i\|^2
  \]
- **K 值确定（双方法交叉验证）**：
  - **肘部法则（Elbow Method）**：绘制不同 K（2~10）的 SSE 曲线，取"肘点"；
  - **轮廓系数（Silhouette Score）**：计算不同 K 的平均轮廓系数，取最大值对应 K。
- **实现**：`KMeans(n_clusters=K, init='k-means++', n_init=10, random_state=42)`；
- **局限性验证**：记录 SSE、迭代次数、各簇样本量与质心，分析对离群点的敏感性（离群点会被强行划入某一簇）。

#### 3.4.2 DBSCAN 方案

- **原理**：基于密度可达性聚类，将"邻域半径 eps 内样本数 ≥ min_samples"的核心点与其密度相连的点聚为一簇，其余标记为噪声（-1）：
  - `eps`：邻域半径，决定聚类的粒度；
  - `min_samples`：核心点判定阈值，通常 ≥ 特征维度 + 1。
- **参数确定**：
  - **K-距离图法**：计算每个样本到其第 k（k = min_samples）近邻的距离，排序绘制曲线，取"拐点"作为 eps；
  - **网格搜索**：对 eps、min_samples 做小范围网格搜索，以轮廓系数（含噪声样本）或 DBI 为准则优选。
- **实现**：`DBSCAN(eps=..., min_samples=..., metric='euclidean')`；
- **特点验证**：记录簇数量、噪声点占比、各簇规模，分析其对离群客户（噪声）的自动识别能力。

#### 3.4.3 对比维度设计

| 对比维度 | 具体内容 |
|----------|----------|
| 聚类数量与结构 | 簇数、各簇样本量分布、是否有噪声点 |
| 内部质量指标 | 轮廓系数、Davies-Bouldin 指数、Calinski-Harabasz 指数 |
| 簇的可解释性 | 各簇 R/F/M 均值画像（如"高价值活跃客户""沉默流失客户"） |
| 鲁棒性 | 对离群点/噪声的处理能力、参数敏感性 |
| 计算效率 | 运行时间、收敛性 |
| 业务落地性 | 分群结果能否映射为可执行的营销策略 |

### 3.5 评估指标

#### 3.5.1 内部评估指标（无需标签）

| 指标 | 公式/说明 | 优劣判定 |
|------|-----------|----------|
| 轮廓系数 Silhouette | \(s = \frac{b-a}{\max(a,b)}\)，a 为簇内平均距离，b 为最近簇平均距离 | 越接近 1 越好；>0.5 表示聚类结构合理 |
| Davies-Bouldin 指数（DBI） | 簇内散度与簇间距离之比的平均 | 越小越好（簇内紧凑、簇间分离） |
| Calinski-Harabasz 指数（CH） | 簇间方差与簇内方差之比（含样本量归一） | 越大越好 |

#### 3.5.2 业务评估指标

- **客户价值分层合理性**：各簇 R/F/M 均值的业务解释是否清晰（如是否存在明显的高价值簇与低价值簇）；
- **营销可执行性**：每个簇是否能够映射出明确的营销策略（优惠券、挽留、升级、流失预警）；
- **噪声点业务含义**：DBSCAN 识别出的噪声客户是否为"一次性异常消费/数据异常"客户。

#### 3.5.3 可选外部评估（拓展）

由于数据无标签，可**构造业务伪标签**（如以消费金额中位数划分"高/低价值客户"）后用 **ARI（调整兰德指数）**、**NMI（标准化互信息）** 间接评估两种算法与业务分层的一致性，作为对比的补充证据。

2. **数据探索（EDA）**：查看数据形状、缺失值、字段类型、Country 分布、时间跨度，绘制 Quantity/UnitPrice 分布直方图，识别异常模式；
3. **数据清洗**：执行 3.2 节预处理流程，记录每一步剔除的行数与理由（保证可复现）；

5. **特征标准化**：对 R/F/M 做变换与标准化，得到建模矩阵 `X_scaled`；
6. **K-means 建模**：肘部法则 + 轮廓系数选 K；建模后输出各簇统计画像；
7. **DBSCAN 建模**：K-距离图初选 eps，网格搜索微调；输出簇与噪声分布；
8. **对比评估**：计算 3.5 节指标，绘制 PCA/t-SNE 聚类散点图、各簇 R/F/M 箱线图，形成对比结论；
9. **业务解读**：为客户簇命名（如"高价值忠诚客户""高潜力新客""流失风险客户""价格敏感低频客户""异常噪声客户"），给出营销策略；
10. **撰写报告**：整理实验过程、图表、结论，形成完整项目报告与演示材料。

## 五、项目总结

1. **成果总结**：完成 Online Retail 电商客户分群全流程——数据清洗 → RFM 特征工程 → K-means/DBSCAN 双算法建模 → 多维度对比评估 → 客户价值分层与营销建议；
2. **算法对比结论（预期）**：
   - K-means 在簇结构规整、计算效率、参数可解释性方面占优，适合常规客户分层；
   - DBSCAN 能自动识别噪声客户（如一次性高额消费或数据异常客户），对簇形状更鲁棒，但参数（eps）敏感、易受高维密度不均影响；
3. **业务价值**：输出明确的客户价值分层体系，为差异化营销、客户挽留、价值提升提供数据支撑；
4. **能力提升**：系统掌握聚类算法原理、scikit-learn 使用、无监督评估方法与数据工程实践。

## 六、项目展望

1. **特征扩展**：在 RFM 基础上引入更多客户特征——购买品类多样性、平均客单价、活跃天数、流失预警时间窗、最近购买商品类别等，构建更精细的客户画像；
2. **算法扩展**：对比层次聚类（Agglomerative）、Gaussian Mixture（GMM）、谱聚类等更多算法，形成聚类算法横向对比矩阵；
3. **时序建模**：按月/季滚动计算 RFM，刻画客户价值迁移轨迹（如"高价值→流失"预警），结合 LSTM/Transformer 做客户流失预测；
4. **标签增强**：将聚类分群作为特征注入监督模型（如客户流失预测、购买意向预测），形成"无监督 + 监督"融合方案；
5. **工程化落地**：将聚类流程封装为可复用 Pipeline，部署为离线定时任务或在线推荐接口，对接实际业务系统；
6. **深度学习探索**：使用自编码器（AutoEncoder）做特征表示学习后再聚类，提升高维特征下的聚类效果。
