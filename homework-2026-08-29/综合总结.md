# 四网络对比实验综合总结（CPU-MNIST / GPU-MNIST / MPS-CIFAR）

本目录下完成了三组"四种经典 CNN 对比"实验。本文把三份结论放在一起，
总结四个网络各自的特点与不同、跨实验不变的结构级结论，以及超参数实验的可迁移教训。

|---|---|

| GPU × MNIST | [homework-2026-08-29-gpu-mnist/结论.md](homework-2026-08-29-gpu-mnist/结论.md) |
| MPS × CIFAR-10 | [homework-2026-08-29-mps-cifar/结论.md](homework-2026-08-29-mps-cifar/结论.md) |

**三组实验的设置**（配方不同，所以跨组只比结论方向，不比数字）：

| | CPU-MNIST | GPU-MNIST | MPS-CIFAR |
|---|---|---|---|
| 任务 | MNIST 28×28 灰度 | 同左 | CIFAR-10 32×32 彩色 |
| 硬件/后端 | 本地 Mac，CPU（oneDNN） | AutoDL RTX 4090（cudnn） | Mac Mini M1（MPS） |
| 模型规模 | 0.27 ~ 4.82M（小适配版） | 同左（models.py 逐字节相同） | 6.01 ~ 14.72M（大适配版） |
| 基线配方 | SGD lr=0.01，bs=64，5 epochs | 同左 | SGD lr=0.1+cosine，bs=128，wd=5e-4，10 epochs，crop+flip |
| 附加实验 | lr/优化器/bs/cosine/augment 单变量；20 轮 2×2 因子 | 全部复跑 + 噪声本底实测 | AlexNet 核大小消融；ResNet/VGG lr 与优化器消融；无增强消融 |

三组实验合起来回答两类问题：**换架构能换来什么**（第一、二节），**换超参能换来什么**（第三节）。

## 一、四个网络的特点与不同

### 总对比表

| | AlexNet (2012) | VGG (2014) | GoogLeNet (2014) | ResNet (2015) |
|---|---|---|---|---|
| **结构签名** | 5 层卷积 + 大核 + 重 FC 头 + Dropout | 全 3×3 堆叠，"同感受野、更少参数、更多非线性" | Inception 多尺度并行 + 1×1 降维 | 残差捷径，梯度有不经过权重 的回传通路 |
| **参数效率** | 差（参数大头在 FC 头） | 中（适配版用 GAP 砍掉 FC 头） | **最好**（三套实验参数都最少） | 中 |
| **每 FLOP 成本** | **最低**（大 GEMM 对硬件友好） | 中 | **最高**（算子多、分支串行） | 中低 |
| **MNIST 精度画像** | 99.26 / 99.32 | 99.29 / 99.25 | 99.36 / **99.40** | **99.37** / 99.38 |
| **CIFAR 精度** | 84.8%（3×3 版 86.3%） | 76.6%（垫底） | **89.5%（第一）** | 85.3%（未发挥） |
| **对配方鲁棒性** | 较好（浅） | **最差**（无残差单路径） | 好（辅助分类器深监督） | **最好**（捷径直达浅层） |
| **一句话定位** | 深度学习的起点，设计靠手工 | 把手工选择变成一条规则 | 不再统一用一种核 | 让深度对配方免疫 |

（MNIST 两列分别为 CPU / GPU；两者极差 ≤0.15pp，**排序在噪声内不作数**。
CIFAR 四网络极差 12.9pp，排序是真实的。这个对比本身就是第二节结论 1 的证据。）

### AlexNet —— 深度学习的起点，性价比来自"浅"

- **签名保留**：首两层大核（11×11 砍到 5×5）+ 三层连续卷积 + 重 FC 头 + Dropout。
  MNIST 版是四网络里唯一没加 BatchNorm 的（历史忠实，BN 2015 年才出现）——
  因此它精度垫底有多少来自缺 BN 无法区分，是实验一的已知混淆变量；
  CIFAR 版统一加了 BN，无此混淆。
- **成本画像跨三套实验一致**：每 FLOP 成本最低（重活是大矩阵乘，对 CPU/GPU/MPS 都友好），
  但 FLOPs 总量最大（MNIST 168.6 MFLOPs，是 VGG 的 7.5 倍）——所以 CPU 上它最慢
  （421s），GPU 上它反而最快（6.8s，62× 加速，管线地板效应下大 GEMM 最不吃亏）。
- **精度画像**：MNIST 上与其他网络不可分；CIFAR 上 84.8%，被 ResNet 反超。
  有趣的细节：CIFAR 消融把它首两层换回全 3×3 后 +1.4pp 到 86.3%，重新反超——
  说明"AlexNet 短周期性价比高"的一部分功劳其实来自小核适配，不是 5×5 大核本身
  （大核开局占便宜：e1 39.2% vs 35.7%，小核后劲赢到最后）。
- **定位**：证明了深度 + 非线性 + GPU 的可行性，但核尺寸、通道数全靠手工拍板；
  参数效率差（原版 60M 参数里 58M 在 FC）。它被取代的方式正是后三者的论文标题。

### VGG —— 把手工选择变成一条规则，代价是对优化最敏感

- **签名**：全部用 3×3 小核堆叠。两个 3×3 感受野 = 一个 5×5，但参数 −28%、非线性 ×2。
  这条规则被 CIFAR 的消融直接验证：同一骨架上 3×3 版用 −3% 参数、−24% 计算量、
  −17% 耗时换 +1.4pp。
- **MNIST 上是性价比冠军**：1.13M 参数 / CPU 117s 一轮 / 99.29%，四组超参实验都选它当载体的
  理由。GPU 上它的耗时优势被"每 batch 固定开销"地板压平（8.1s，与 AlexNet 差距远小于
  FLOPs 差距），但 bs256 一项就拿到 3.1× 加速，说明它的大矩阵乘在 GPU 上喂得饱。
- **CIFAR 上垫底（76.6%），而且失败方式非常有信息量**：前 3 个 epoch 完全卡在随机水平
  （train acc 11~12%，test loss 2.26 ≈ ln10）。这不是表达力问题，是优化问题——
  它是四网络里唯一的"13 层无残差单路径"，大步长下参数在随机初始化平台附近打转，
  而其他三个各有逃生通道（AlexNet 靠浅、ResNet 靠捷径、GoogLeNet 靠辅助头）。
  只把 lr 降到 0.01，同一个模型 +11.5pp 跳到 88.1%——**对配方的鲁棒性本身就是结构的属性**，
  这条是三组实验里最接近"论文动机复现"的发现（VGG 空转 vs ResNet 同配方 85.3%，
  正是 ResNet 论文要解决的问题）。
- **注意与 MNIST 超参结论的表面矛盾**：MNIST 上 lr 在 100 倍区间内不敏感（BN 的功劳），
  CIFAR 上 lr 一档就是 +11.5pp。两者不矛盾：**BN 解决梯度尺度问题，解决不了
  无残差深路径的优化难度**；lr 敏不敏感，取决于结构而不取决于 BN。

### GoogLeNet —— 参数效率之王，速度上的付费用户

- **签名**：Inception 模块，同一层并行跑 1×1 / 3×3 / 5×5 和 pool，再用 1×1 把通道压窄
  后才算贵的卷积。CIFAR 版还带两个辅助分类器（深监督，各占 loss 0.3 权重）。
- **精度**：三套实验里表现最稳的网络——MNIST 两套都与 ResNet 并列前二（99.36 / 99.40，
  差距在噪声内不能排名），CIFAR 上以 89.5% **明确第一**，且用的是最少的参数
  （6.01M，不到 VGG16 的一半）。
- **成本**：每 FLOP 成本在三套实验里**全部最高**（MNIST CPU 11.05 s/MFLOP，是 VGG 的 2.1 倍；
  GPU 0.58，仍有 1.6 倍；MPS 上每 GMAC 0.55s，约 VGG 的 1.9 倍）。原因是它算子最多、
  Inception 四分支在 eager 执行下串行，启动与访存开销吃掉了小卷积的理论优势。
  换 GPU 能掩盖一部分（CPU 版实验留下的"待验证"已验证：掩盖了，但没掩盖完——
  GPU 上它仍是最慢的）。
- **定位**：GoogLeNet 卖的从来是参数效率不是速度。它和 VGG 一起代表了两种省钱路线：
  VGG 用规则把卷积做得规整（对硬件友好），GoogLeNet 用结构把参数做少（对硬件挑剔）。

### ResNet —— 让深度对配方免疫

- **签名**：残差捷径 `输出 = ReLU(body(x) + short(x))`，梯度有不经过任何权重的通路。
  主干最深（MNIST 适配版 13 层串行卷积，CIFAR 用 18 层）。
- **精度**：MNIST 上与 GoogLeNet 并列前二（99.37 / 99.38）；CIFAR 上 85.3% 排第二，
  但这是 10 epochs "没训够"的数字——曲线到第 10 轮仍在明显上升，换到各自最优配方后
  它以 89.6% 登顶全场。
- **鲁棒性**：三套实验里对配方最不挑剔的网络。CIFAR 上同样的 lr=0.1，VGG 空转 76.6%、
  它有 85.3%；lr 降一档它 +3.7，VGG +11.5——**有捷径的网络不需要"对的配方"保命**。
  MNIST 20 轮里它也是唯一没有出现明显退化的深网络。
- **定位**：直接解决 VGG 暴露的问题。**"VGG@lr0.1 的 76.6% vs ResNet@lr0.1 的 85.3%"
  这组同配方数字，就是 ResNet 论文的动机本身。**

## 二、跨三组实验不变的结构级结论

1. **架构对精度的影响随任务难度增长。** MNIST（极简任务）上四网络极差 0.11~0.15pp，
   两套硬件都排不出可靠次序；CIFAR 上极差 12.9pp，排序明确且稳定。
   **简单任务上挑架构其实是挑成本，难任务上才是挑架构。**
2. **参数量与精度完全脱钩。** 参数最少的 GoogLeNet 在三套实验里精度都最高或并列最高
   （0.27M/99.40、6.01M/89.5%），参数更多的 VGG/AlexNet 反而在 CIFAR 上垫底。
   看参数量选网络没有意义。
3. **每 FLOP 成本的排序是架构的性质，具体数字是硬件的性质。**
   "多分支小算子每 FLOP 更贵"在三套实验里全部成立（GoogLeNet 三次垫底），
   "重 FC 头/大 GEMM 每 FLOP 更便宜"也全部成立（AlexNet 三次最优）；
   但谁"最慢"随硬件重排——AlexNet 在 CPU 上最慢、在 GPU 上最快。
   **想得到可迁移的结论，就记录排序和方向；单点数字只属于测它的那台机器。**
4. **决定耗时的从来不是参数量，但"决定它的东西"随硬件变**：CPU 上近似 FLOPs
   （VGG 22.6 vs AlexNet 168.6 MFLOPs ↔ 117s vs 421s）；MPS eager 上是算子数
   （GoogLeNet 189 个算子，比 VGG 慢 2.9 倍）；GPU 小模型上是"每 batch 固定开销 × batch 数"
   的地板（AlexNet 7.5 倍 FLOPs 却比 VGG 快 16%，bs256 一项 3.1× 加速）。
5. **对超参的鲁棒性是结构的属性。** 无残差单路径（VGG）最敏感，有逃生通道的结构
   （浅 / 捷径 / 辅助头）不敏感。这条在 CIFAR 上量化得很清楚（+11.5 vs +3.7）。
6. **单 seed 下 0.1~0.2pp 级的差异不能当结论。** GPU 实测运行间噪声本底 0.1~0.4pp；
   CPU 版曾据 −0.20pp 判"Adam 显著更差"，GPU 复跑变成 +0.04 无差异——
   刚过判定线的结论（无论正负）都要跨硬件复验后才可信。

## 三、超参数实验结论汇总

按"证据强度"组织：✅ = 多组实验一致；⚠️ = 单组或方向不稳。

**1. 训练轮数是最便宜的提升 ✅**
MNIST 上 5→20 轮 +0.24（CPU）/ +0.29（GPU），超过任何单项超参的收益。
但 CIFAR 提醒了另一面：轮数不足时排序会失真（ResNet 85.3% 是"没发挥"而非上限），
**比较架构必须先保证大家都在各自的收敛平台上**。

**2. 学习率：没有绝对的好坏，最优值依赖结构与预算 ✅**
- 有 BN 的浅任务（MNIST）：0.001~0.1 的 100 倍区间内差异 ≤0.03pp，两套硬件复现
  ——不值得做 lr 网格搜索；
- 无残差深网络 + 大 lr（CIFAR）：VGG 前 3 轮完全空转，lr 降一档 +11.5pp；
  有残差的 ResNet 同场景只 +3.7pp——**敏感性由结构决定**；
- lr=0.1 是为长训练设计的配方，短预算下全面吃亏（CIFAR 上 Adam 和 lr=0.01 都比它强）。

**3. 优化器：Adam 不是"换上就更好"的替代品，且结论跨环境不稳 ⚠️**
三套实验三个样：CIFAR 短预算下 Adam(lr=0.001) 全场最高（89.6%，+4.2）；
MNIST CPU 上唯一显著变差（−0.20，还有 e3→e4 大回退）；MNIST GPU 上 +0.04 无差异、
回退签名消失。公平性注记：比的始终是"未调参 Adam vs 已调参 SGD"，且 Adam+L2 ≠ AdamW。
**可迁移的只有一句：短预算、想省调参功夫时 Adam 值得一试；但它没有稳定优势。**

**4. cosine 调度：加速收敛，不提高上限 ✅（跨轮数翻转本身也复现了）**
MNIST 5 轮 +0.20 / +0.26（预算紧时最佳单项）；20 轮 −0.04 / −0.03，最佳轮同停 e9，
机制两套硬件对得上（train 100%、损失 3e-4，损失面塌平后调度器无事可做）。
**预算紧张时开，预算充足时收益归零。**

**5. 数据增强：最重要的正则项，短期精度收益小 ✅**
MNIST：单看精度 5 轮 +0.18 / +0.21、20 轮 +0.04 / +0.06，都不大；
但它是唯一压住 train-test gap 的配置（0.49→0.08 / 0.51→0.13），且 20 轮末训练损失
仍是 0.013~0.014（无增强组全部塌到 1e-4）——模型背不下增强后的数据，损失面不塌。
CIFAR 反向验证：去掉增强后 train 99.5%、gap 拉到 15.5pp，教科书式过拟合。
**增强的价值在泛化健康度，不在榜面精度；训练拉长后差距才会显现。**

**6. cosine × augment 交互：方向对，幅度不稳 ⚠️**
MNIST 20 轮：单独 cosine −0.04、单独 augment +0.04，组合 +0.14（CPU，e9 起连续领先）；
GPU 复跑交互 +0.06，在本底内。机制自洽：augment 让损失面不塌，调度器才有发挥空间。
**教训有两条：单变量实验看不见交互（只做单变量会得出"两个都没用"）；
交互幅度小于 0.2pp 时需要多 seed 才能定案。**

**7. batch size：精度不敏感，吞吐收益是 GPU 现象 ✅**
MNIST：精度 ±0.13pp 内（测试曲线无泛化变差信号）；吞吐 CPU 只快 4%、GPU 快 3.1 倍。
CPU 版预言的"大 batch 收益是 GPU 现象"被 GPU 侧实测证实。
**想省时间：GPU 上直接把 batch 开大；CPU 上开大没意义。**

**8. 核大小（CIFAR 消融，VGG 规则的直接检验）✅**
同一条 AlexNet 骨架，首两层 5×5 → 3×3：参数 −3%、计算量 −24%、耗时 −17%、精度 +1.4pp。
"同样感受野、更便宜、还能堆得更深"——VGG 的核心论点在小实验里就能复现。

## 四、实践建议

**简单任务（MNIST 类，架构间差距 <0.2pp）：**
- 别在架构上花时间，挑最快/最方便的；收益全部在配方里：
  GPU 上 VGG+cosine+augment 20 轮 = 2.7 分钟拿 99.63%（同样的配方 CPU 要 45 分钟）；
  预算再紧就 cosine 5 轮；赶时间开 bs256，精度不亏。

**难任务（CIFAR 类，架构间差距以 pp 计）：**
- 优先有残差的结构；给无残差深网络配小 lr（或 warmup）；
- 增强必开（它的价值随训练时长增长）；短预算想省事用 Adam 试试，但别指望稳定收益；
- 各网络取各自最优配方后的上限（CIFAR）：ResNet 89.6 > GoogLeNet 89.5 >
  VGG 88.1 > AlexNet 86.3——**"结构 × 配方"要一起报，单报结构排名会被配方混淆。**

## 五、方法论教训（三组实验合账）

1. **稳固的结论是方向和排序，不是数字。** 跨硬件复现的 8 条 MNIST 结论全是方向级；
   翻转的 Adam 恰好是贴着判定线的那条。
2. **区分"架构的性质"和"硬件/环境的性质"**，最便宜的手段就是换一个硬件重跑一遍
   （每 FLOP 成本排序不变 = 架构性质；"谁最慢"重排 = 环境性质）。
3. **显著性要有判定线，判定线附近要实测噪声本底**（GPU 同配置复跑 30 秒量出 0.1~0.4pp），
   单 seed 的边界结论一律视为待复验。
4. **判断过拟合按信号可靠性排序**：测试曲线见顶回落 > 最佳轮远早于末轮 > train loss→0 >
   gap 变大。gap 单独不能定罪——MNIST 上 CPU+GPU 三十来组 run，gap 都不小但没有一组
   出现明确的测试曲线回落，过拟合不是这个任务的主要矛盾。
5. **单变量对照归因清晰，代价是看不见交互**；2×2 因子实验是为交互而做的。
6. **公平比较锁死配方，但汇报时补一份"各自最优配方"**——前者归因干净，
   后者才看得到结构上限（VGG 因此从垫底回到 88.1%）。
7. **测耗时先找地板**：小模型 × 小数据的 s/epoch 可能测的是数据管线和 kernel 启动
   而不是模型；用 batch 扩大几倍看耗时是否线性下降，可以快速判断测到的是什么。
